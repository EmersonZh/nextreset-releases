Reset 1.8.3 tells you when a saved account needs you.

- **The rail says "Needs sign-in".** When a saved Codex or Claude account's sign-in has expired or
  its last check failed, the rail bubble now shows that in red on the account's own row instead of
  only "Updated 3d ago", so an expired sign-in no longer looks like a refresh that never finishes.
  The accounts window keeps its Sign in again action.

Reset requires an Apple-silicon Mac running macOS 26 or newer. Existing installs update through
the built-in updater.
